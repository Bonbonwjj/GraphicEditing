# Plot Forge v0.2.2

发布日期：2026-11-03

## 下载与使用

Windows 64 位用户下载 `Plot-Forge-v0.2.2-Windows-x64.zip`，完整解压后运行 `Plot Forge/Plot Forge.exe`。已包含 Python、Git 和绘图库，无需另行安装。首次启动需要解压运行环境，请等待启动页完成。

继续开发请下载 `Plot-Forge-v0.2.2-source.zip`。本次提供 Windows 安装包和跨平台源码；macOS 用户可按 `docs/DESKTOP_APP.md` 自行构建。

## 主要变化

- 全图缩略浏览，当前图高清交互；多子图支持放大单个子图编辑。
- 组件编辑只保存实际修改的属性，保留原有坐标轴名称、数据和布局。默认锁定位置，可切换到拖动模式。
- 箱型图、小提琴图和均值误差线支持整体与单个组件选择；箱体、须线、端帽和中位线按分组编辑。
- 散点可调整颜色、透明度、大小和形状，范围为该组全部散点或仅该组离群散点，其他组保持原样。均值点可独立选择。
- 同一组配对数据的连线同步修改颜色、粗细、透明度和线型；选中框加粗。
- 坐标轴范围、刻度位置和刻度线同步更新；支持标签回车换行、RGB 输入、色卡与透明度。
- 新增文本框和线条，支持删除、撤销及虚线选择。
- 优化交互预览缓存、文件夹选择和原生工程导入；聊天改图自动补充可读取的工程上下文，并验证候选布局。
