## 范围与限制

- 此次安装包仅为 Apple 芯片内部预发布测试包；未构建 Intel 或 Windows 安装包。
- 模型测试使用模拟响应与真实本机出图，不代表真实模型始终能正确生成代码；没有请求公司模型或验证 VPN、个人 GitHub 凭据。
- 回归与项目接口测试使用空钥匙串后端，原生个人 Keychain 保存/读取交互尚未验收。
- 默认 /var 等符号链接祖先路径可能被已有路径检查拒绝的问题未在本次改动中修复。
- 源码直接启动识别 canonical data/code 初始项目的兼容问题仍存在；App 打包资源准备阶段会转换目录，包内附带项目已验证可识别。
- 转换图型的自动完整样本核对目前覆盖可解析 CSV 分组的单子图箱线图/小提琴图；其他来源、多子图或自定义图元会报告无法核对。
- 构建、冒烟和功能检查均使用隔离工作区；验证启动的临时后台已停止，个人日常工作区未被更新或发布。
