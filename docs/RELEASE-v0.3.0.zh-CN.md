# Plot Forge v0.3.0

发布日期：2026-11-10。发布分支：`lc`。

## 当前行为

- 直接读写 `X:\figure_DATA_code\projects` 中的同一份公共工程；每位成员在本机运行平台、配置自己的账号。正式代码、数据、图片与历史统一保存在公共目录。
- 工程写入使用跨进程文件锁。图表保存核对基础版本，防止旧页面覆盖其他成员刚保存的图表；Chat 候选继续检查生成时的源码版本。
- 子图、子图序号与普通组件可以拖动；已选框和拖动把手可直接抓取，预览跟随位置，并按屏幕帧合并更新。
- 同组散点、离群点及配对连线端点联动，拖动配对线时同组配对线及对应散点一起移动。
- 支持单子图绘图类型下拉多选、组别配色保留、均值点样式联动、轴范围修改与布局保持、正式代码历史保留和更快的交互/Chat 预览。

## 启动包

`releases/v0.3.0/Plot-Forge-v0.3.0-team.zip` 是源码启动包，需要 Python 3.11+，首次启动联网安装依赖。解压到本机，双击 `Start-Plot-Forge.cmd`。

公开平台包不包含研究工程、研究数据、个人账号、API 密钥或隐藏 Chat 会话。团队已有的 `jiahui` 工程保留在公共目录。`SHA256SUMS.txt` 用于校验启动包。

完整操作说明见 [团队直接共享工程与启动说明](团队共享文件夹与打包.md)。同一 Figure 建议协调后轮流编辑；本版本不是多人同时操作同一画布的实时协同编辑器。

## 重新打包

```powershell
python tools/package_team_release.py --output dist/v0.3.0
```

默认只打包平台。只有显式传入 `--project <工程名>` 才生成额外的工程初始备份；含研究数据的工程备份不要提交到公开 GitHub 仓库。

历史 v0.2.2 的发布工作流仅保留手动入口，避免本次版本变更误触发旧版本发布。
