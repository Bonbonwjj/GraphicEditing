# v0.1.3 更新说明

发布日期：2026-10-21。源码分支：lc。

- Chat 改图支持上传或粘贴参考图片（最多 3 张，每张 6 MB）。视觉 Agent 先提取关键特征，绘图 Agent 生成代码，再读取实际候选与参考图逐项比较。
- 参考特征按图片版本缓存；读图、生成、修复与视觉对照共用每图每轮最多 3 次模型调用，未完成核对会明确提示。
- 统一配对数据处理：先筛选当前指标，检查条件内受试者 ID 唯一性，再按 ID 配对；保留未配对样本，修复半小提琴和连接线的绘制与核对。
- 分类轴横向排版偏移不再误判为观测值变化；观测值、配对端点和显示效果分别报告。
- 所有候选检查均为提示，不再禁用“应用此版”和“选此版本继续更改”。包括数据/图型/布局/字体/坐标/标注差异、旧版本及已放弃候选。有代码即可继续或尝试应用；没有图片时先执行代码，实际执行或写入失败会返回错误，正式图不会被部分覆盖。
- 应用沿用历史备份，不增加额外确认步骤；既有参数快速修改、等距坐标刻度和 API 连接监测保留。

## 安装与验证

Mac 安装包适用于 Apple Silicon（M 系列）芯片。应用包含 Python 与 Git 运行环境。

发布流水线会执行相关后端和前端回归、应用源码一致性检查、macOS 签名校验，以及独立中文/空格目录下无系统 Python/Git 的首次启动测试。实际构建结果与 SHA256 随发布附件提供。

应用沿用 ad hoc 签名，未作 Apple Developer ID 公证；此版本按预发布提供。模型视觉核对为辅助信息，不构成科学含义的全面验证。
