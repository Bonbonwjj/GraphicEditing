上游：LY `05227e016aec1c5f440662bdd0a22bc737cd606c`。合并前本机源码副本位于 `.merge-backups/`，未包含 API 密钥、Git 凭据或虚拟环境。

- GitHub 拉取/发布，草稿与个人配置不参与共享。
- 默认本机 Python、双击启动、内网 HTTP 模型配置和团队默认模型。

- 表格子目录、显式 charts/lib 目录、数据源元数据。
- 可编辑共享绘图模块、独立历史、模型建议和代表图验证基础。
- 可配置普通渲染超时、项目 lib 搜索路径与可选 Git 容错。
- 对应单元测试及真实 Bundle 手动验证脚本。

## 按本次用户决定调整

1. 同一共用函数或同一模块变量的修改默认使用代表图；多个函数/变量的独立修改则验证全部项目图，也可主动要求全量验证。AST 归类为静态近似，不保证完全理解改动语义。
2. 共享模块验证通过只生成候选，不立即改正式代码。展示图片、影响范围和检查限制，用户确认后才应用；可以基于编辑器候选继续修改。期间正式代码/数据变化则拒绝旧候选。
3. 所有日常共享以 GitHub 为准。Bundle 默认复制进项目并使用相对路径；从本机目录导入也会复制，无需 NAS。LY 的外部引用接口只作兼容，不作为默认入口。
4. Bundle 原始字节不进行换行转换，随项目保存 .gitattributes 保护哈希；不发布绝对本机路径、绑定配置或模块草稿。
5. 单文件超过 95 MiB 会明确阻止普通 Git 发布，原文件仍留本机；尚未接入 Git LFS。浏览器单次 500 MB，目录复制可用于更大数据包，当前共享项目总量上限 2 GiB。

## 特别衔接

Bundle renderer 常先保存中间图再复制最终 PNG，因此增加输出观察器，捕获被选中的实际 Matplotlib Figure 后接入已有候选检查，避免把 PNG 当作可验证的原始绘图对象。无法捕获的自定义 renderer 不会被报告为检查成功。

共享模块临时库同时覆盖直接 import 与 projects.<id>.lib 的限定导入；临时库不复制 __pycache__，避免误验证正式模块或旧字节码。Bundle 不在启动或信任后一次性渲染全部图，只在点击图卡时按需生成。

上游文档保存于 `docs/ly-original/`，其中的环境变量、LLM 调用和自动保存描述属于 LY 原版；合并后的行为以 README 和本记录为准。

验证范围包括两个 Git 成员工作区、Bundle 字节往返、合成 Group/Border 的真实 PNG 与候选渲染、共享模块候选/人工应用/连续修改/陈旧版本拒绝。尚未提供同事的真实大型 Bundle，因此未据此宣称真实实验数据的兼容性，也未完成 macOS 真机验收。
