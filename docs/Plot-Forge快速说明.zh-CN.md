# Plot Forge 快速说明

用自然语言修改 Python 科研图表：**打开工程 → 输入要求 → 审阅候选 → 确认应用**。

## 核心功能

- **工程准备**：导入 Python 代码和数据，拆分绘图入口；已拆分工程下次直接打开。
- **对话改图**：调整配色、字体、坐标轴、图例和布局，按数据条件转换图形类型。
- **先看再应用**：候选图与正式版本分开，确认后才更新；不满意可继续修改。
- **保存与追溯**：命名保存会话、查看修改历史、下载标准工程备份。
- **灵活连接**：支持本地 / 内网、自定义兼容 API、硅基流动和获准的 ChatGPT 订阅连接。

## 四步开始使用

1. **连接模型**：顶部“API 配置”填写服务地址、模型和 Key，或通过官方页面登录 ChatGPT 并确认代码发送权限。
2. **打开工程**：已拆分工程直接打开；新工程先导入、拆分并完成验证。
3. **输入修改要求**：选中目标图，例如“改成散点图，横纵坐标轴加粗，其他保持不变”。
4. **审阅并应用**：查看候选图片和警告，满意后点击“应用此版”。

## 常用操作

| 想做什么 | 使用入口 |
| --- | --- |
| 修改上一版候选 | 选择该版本继续对话 |
| 查看代码或数据 | 中央“绘图代码”“CSV 数据”标签 |
| 生成太慢 | 点击“停止本轮”，正式版本不变 |
| 保存或删除对话 | 右侧“保存会话”“删除会话” |
| 保存工程成果 | 下载标准工程备份 |

## 三点注意

1. **云端模型会接收授权资料。** 本地网页不等于本地推理，敏感代码和数据发送前须审阅。
2. **候选不是最终结果。** 数据、单位、显著性和画面仍需人工检查；无法保证所有请求都成功或秒级完成。
3. **备份与删除要分清。** 标准 ZIP 不含对话和未应用候选；删除会话移入本机回收目录，删除工程副本则不可撤销，但不删除原始目录。
