# Plot Forge v0.3.1

发布日期：2026-11-11。发布分支：`lc`。

## 统计图移动联动修复

- 按单根柱子、单个均值点识别移动组，关联误差棒、端帽、组别刻度与标签；同一容器中的相邻组保持独立。
- 同时支持横向图、单独绘制的误差棒和非对称区间。记录绘图时的真实中心位置，避免将非对称区间的中点误认为均值。
- 比较括号、星号与独立绘制的端部短竖线跟随对应组；支持 LineCollection、figure 文字和带 offset points 的 annotate 标记。
- 箱型图、小提琴图、均值误差图与茎状图使用相同的移动归属与刻度联动。共享均值连线的移动会带动对应误差棒与端帽。
- 拖动预览包含误差棒与端帽；均值连线只改变被移动端点，保存后重新渲染仍保持一致。兼容旧位移配置，避免重复叠加。

以上修复只改变展示位置，不重写冻结数据或统计值。修复验证包含 110 项相关 Python 测试、前端拖动检查及保存源码后在隔离渲染器中重绘的检查。

```text
X:\figure_DATA_code\

  projects\jiahui\          # 团队当前共用的代码、数据、图片与历史

```

部署保留公共工程中的当前文件，不使用本机旧副本覆盖团队代码、数据或历史。每位成员仍将启动包解压到本机运行；平台源码目录供查看和部署核对，不用于多人共用账号配置。

## 启动与更新

下载 `Plot-Forge-v0.3.1-team.zip`，解压到新的本机目录，双击 `Start-Plot-Forge.cmd`。需要 Python 3.11+，首次启动联网安装依赖；各成员使用自己的模型账号配置。所有成员继续访问同一公共工程。

GitHub `lc` 分支只发布平台及已有公开示例，不上传 `jiahui` 研究工程、API 密钥或隐藏 Chat 会话。历史 v0.3.0 发布文件保留。
