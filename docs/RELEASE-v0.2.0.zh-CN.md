# Plot Forge v0.2.0

发布日期：2026-10-28。源码分支：lc。

## 下载

Windows 64 位解压运行包：[Plot-Forge-v0.2.0-Windows-x64.zip](https://github.com/Bonbonwjj/GraphicEditing/releases/download/v0.2.0/Plot-Forge-v0.2.0-Windows-x64.zip)。
完整解压后双击 `Plot Forge.exe`。软件包含 Python、绘图库和 Git。

## 本次版本

- 默认绘图环境优先，保留独立环境复现选项。
- 导入、拆分进度和成功、失败、被阻止原因显示。
- 已有画布遇到可识别的布局断言时显示实际预览和红色警告。
- 支持可见子图到内部轴的索引、源码定位、按需读取和当前图局部修改；无法可靠识别的映射需要手动指定。
- 修复按需读取源码的范围问题：大范围自动分段、EOF 越界调整、数字字符串兼容，以及无效请求反馈后继续。
- 允许审阅、应用和基于含警告的候选继续修改。

## 验证

Windows EXE 已在隔离目录完成首次运行，确认使用包内 Python/Git，成功生成 PNG 并通过本地服务健康检查。启动器 6 项测试通过；本次源码读取修复 18 项定向测试通过。子图编辑此前 91 项相关检查通过；扩大测试时的 2 项既有删除测试被路径符号链接保护拦截，与本次子图功能无关。
