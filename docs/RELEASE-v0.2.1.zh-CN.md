# Plot Forge v0.2.1

发布日期：2026-10-30

## 主要更新

- 图像组件直接交互：点选线条、文字、坐标轴、子图和图例后打开属性窗口。
- 支持线条颜色、粗细、标记大小，子图边框、网格、字号、标题和坐标轴名称调整。
- 图例支持直接拖动；候选修改实时预览，确认前提供修改前后对比。
- 确认后同时更新正式图片、绘图代码和完整历史版本。
- 优化大图加载：保留现有预览，后台准备交互元数据，避免长时间空白。
- 修复命名颜色转换、完整画布显示、原生 JSON 面板映射识别与历史源码保留。
- 保持模型数据最小化策略：原始表格行和图像不发送给云端模型。

## 验证结果

- 完整 Python 测试：391 项，376 通过，9 跳过，6 项既有失败。
- 已知失败集中于聊天候选的散点/箱线图转换和依赖冲突验证，不涉及本版本新增交互流程。
- 交互样式、静态 UI、面板索引和按需预览相关测试通过。
